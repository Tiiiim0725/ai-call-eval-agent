依据：主 PRD `v0.35-draft`；执行文档 `v0.2`

## 已确认的实现范围

- 产品形态：与 Mentor/EvalLab 平行的独立网页工作台。
- MVP 主链路：TXT 导入 → 原始快照/解析 → 目标专家确认 → 证据片段 → 候选知识/变更 → G3/G4 → 新版本 → Prompt/发布包 → G5/人工交付。
- 前端六类入口：工作台、知识更新任务、证据与知识、变更与版本、Prompt 与发布包、审计与设置。
- 任务详情骨架：上下文栏、主工作区、右侧控制/详情栏、底部事件流。
- 必须可见：任务、证据、知识、变更、编译、交付六组参数；状态、Gate、阻断原因、哈希和审计 ID 必须可追溯。
- 硬边界：候选/未批准/冲突未决对象不得进入正式 Prompt；已批准对象不可原地修改；正式 Prompt 不提供手改入口；D3 默认脱敏且导出受限。
